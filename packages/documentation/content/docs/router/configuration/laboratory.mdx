---
title: "laboratory"
---

The `laboratory` configuration object allows you to control the Hive Laboratory interface (the
in-browser GraphQL IDE served by the router).

## Options

### `enabled`

- **Type:** `boolean`
- **Default:** `true`
- **Environment Variable:** `LABORATORY_ENABLED`

The `enabled` property controls whether the Hive Laboratory interface is enabled or disabled.

```yaml title="router.config.yaml"
laboratory:
  enabled: true
```
